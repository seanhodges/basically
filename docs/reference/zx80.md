# ZX80 BASIC reference

Every command, function and operator in Sinclair ZX80 integer BASIC.

**In this reference:** [Hardware](./zx80/hardware) · [Escape codes](./zx80/escapes) · [File formats](./zx80/formats) · [Argument notation](./#argument-notation)

## Notes and caveats

- Arithmetic is 16-bit signed integer only — there is no floating point, and
  division truncates.
- One numbered statement per line; line numbers must be strictly ascending.
  There are no multi-statement lines and no `ELSE`.
- Variable names are single letters (`A`–`Z`, with a `$` suffix for strings);
  strings are taken apart with `TL$` and `CODE` rather than slicing.
- `AND`, `OR` and `NOT` combine their operands bit by bit — `5 AND 3` is `1` and
  `NOT 5` is `-6` — and a true comparison is `-1`. The ZX81 that replaced this
  machine answers `5` and `0` and `1` to the same three expressions, so logic is
  one of the things a program carried between the two Sinclairs has to be read
  for.
- There is no `<=`, `>=` or `<>`. Combine the ones there are: `NOT A<B` is how a
  program says `A>=B`.
- The power operator is `**`, folding left to right, on integers like everything
  else here.
