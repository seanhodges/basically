# ZX80 BASIC reference

Every command, function and operator in Sinclair ZX80 integer BASIC.

## Notes and caveats

- Arithmetic is 16-bit signed integer only — there is no floating point, and
  division truncates.
- One numbered statement per line; line numbers must be strictly ascending.
  There are no multi-statement lines and no `ELSE`.
- Variable names are single letters (`A`–`Z`, with a `$` suffix for strings);
  strings are taken apart with `TL$` and `CODE` rather than slicing.
