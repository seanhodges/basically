# ZX81 BASIC reference

Every command, function and operator in Sinclair ZX81 BASIC.

**In this reference:** [Hardware](./zx81/hardware) · [Escape codes](./zx81/escapes) · [File formats](./zx81/formats) · [Argument notation](./#argument-notation)

## Notes and caveats

- One numbered statement per line; line numbers run 1–9999 and must be strictly
  ascending. There are no multi-statement lines and no `ELSE`.
- Variable names are single letters (`A`–`Z`, with a `$` suffix for strings).
- Keywords are entered as whole words and stored as single-byte tokens; the
  character set has no lower case.
